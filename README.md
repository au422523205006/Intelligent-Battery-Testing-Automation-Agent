# AI-Powered EV Battery Monitoring and Intelligent Control Agent

An EV battery monitoring, simulation, analysis, and reporting platform featuring a resilient **Multi-LLM Automatic Fallback Agent** built with Python and Streamlit.

---

## ⚡ Key Features

- **Multi-LLM Automatic Fallback Router (`llm_router.py`)**:
  - **Priority 1 (Primary)**: Groq API (`openai/gpt-oss-20b` or `qwen/qwen3.8-27b`)
  - **Priority 2 (Secondary)**: OpenRouter API (`meta-llama/llama-3.3-70b-instruct`)
  - **Priority 3 (Third)**: Google Gemini API (`gemini-flash-latest`)
  - **Priority 4 (Offline)**: Ollama local LLM (`tinyllama:latest` or locally installed model)
  - **Safety Fallback**: Deterministic local rule-based assistant if all providers fail or are unconfigured.
- **Failover & Error Handling**:
  - Automatically switches on Rate Limits (HTTP 429), Quota Exhaustion, Server Errors (HTTP 500/503), Timeouts, and Model Unavailability.
  - Exponential backoff with `Retry-After` header support.
  - Sanitizes and protects API keys: never logs secrets or exposes keys in the UI.
  - Detects invalid API keys safely and skips to the next eligible provider without infinite loops.
- **Battery Test Simulator (`simulator.py`)**:
  - Simulates 50A charging and discharging with realistic pack voltage curves, internal resistance drop, and thermal rise.
  - Configurable safety flags for high temperature (>45°C), over-voltage (>430V), and under-voltage (<310V).
- **Interactive Engineering Dashboard (`main.py`)**:
  - Built with Streamlit and Plotly.
  - Real-time voltage and current telemetry trend charts.
  - Active LLM provider (`GROQ`, `OPENROUTER`, `GEMINI`, `OLLAMA`, `RULE_BASED_FALLBACK`), active model, and automatic fallback alert banners.
  - Session history and downloadable PDF engineering reports (`report_generator.py`).
- **Safety Interlocks & Hardware Mocking (`hardware/`)**:
  - Mock adapters for BMS (CAN/Bluetooth) and test workbench.
  - Physical hardware control is strictly locked and disabled for safety.
  - All telemetry is explicitly identified and logged as simulated data.

## 🔑 Environment Configuration (`.env`)

Copy `.env.example` to `.env`:

```powershell
Copy-Item .env.example .env
```

Edit `.env` to configure your API keys (unconfigured keys are automatically skipped):

```ini
# Configurable Failover Order (Default: 1. Groq -> 2. OpenRouter -> 3. Gemini -> 4. Ollama)
PRIMARY_LLM=groq
LLM_FALLBACK_ORDER=groq,openrouter,gemini,ollama
LLM_TIMEOUT_SECONDS=15
LLM_MAX_RETRIES=2

# 1. Groq (https://console.groq.com/keys)
GROQ_API_KEY=gsk_your_groq_api_key_here
GROQ_MODEL=openai/gpt-oss-20b

# 2. OpenRouter (https://openrouter.ai/keys)
OPENROUTER_API_KEY=your_openrouter_api_key_here
OPENROUTER_MODEL=meta-llama/llama-3.3-70b-instruct

# 3. Google Gemini (https://aistudio.google.com/app/apikey)
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-flash-latest

# 4. Ollama (Local offline)
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=tinyllama:latest

# Fallback Router Settings
PRIMARY_LLM=groq
LLM_FALLBACK_ORDER=groq,gemini,openrouter,ollama
LLM_TIMEOUT_SECONDS=15
LLM_MAX_RETRIES=2
```

## 🚀 Running the Application

### 1. Python Backend (FastAPI)
The FastAPI backend serves all REST APIs, multi-LLM routing, and serves the pre-built React frontend at `http://localhost:8000`:

```powershell
# In project root: C:\Users\Admin\.gemini\antigravity\scratch\ev_battery_agent
uvicorn backend.api:app --host 127.0.0.1 --port 8000 --reload
```
Open **`http://localhost:8000`** in your browser to access the complete React dashboard.

### 2. React Frontend Development Server (Optional / Hot-Reload)
If you want to develop or modify the React frontend with Vite hot module replacement:

```powershell
cd frontend
npm run dev
```
Open **`http://localhost:5173`** in your browser. All `/api` requests are automatically proxied to `http://localhost:8000`.

### 3. Legacy Streamlit Dashboard
The original Streamlit interface is preserved in `main.py`:
```powershell
streamlit run main.py
```

## 🔋 uPowerful BST & BettaTeQ Laboratory Integration

The EV Battery Agent automatically ingests real battery test data generated by **BettaTeQ V5.2** and stored by **uPowerful BST**:
- **Binary Parser Bridge (`backend/connectors/upowerful_bridge.ps1`)**: Interops with 32-bit `DataView.DataAnalyser.dll` under `SysWOW64\powershell.exe` to decode `.main` test archives.
- **Connector (`backend/connectors/upowerful_connector.py`)**: Automatically scans the lab directory (`C:\Users\Admin\Downloads\UPowerful BST(2022.05.21)\UPowerful BST(2022.05.21)\SampleData`), avoids duplicate ingestion, and supports manual `.main` or `.csv` uploads.
- **Strict Data Provenance**: All lab tests are tagged as `IMPORTED_REPORT`.
- **Interactive Visualizations**: Time-series Voltage vs Time, Current vs Time, Temperature vs Time, and Capacity/Energy curves rendered with Recharts.

## 🛡️ Battery Safety Notice
Physical hardware control is completely disabled. The physical BMS is DISCONNECTED. Real-time telemetry is UNAVAILABLE unless originating from software simulation (`SIMULATED`) or imported laboratory tests (`IMPORTED_REPORT`). State of Health (SOH) values are never fabricated without validated reference EIS data.
